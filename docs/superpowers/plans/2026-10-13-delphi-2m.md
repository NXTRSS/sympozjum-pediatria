**Dane syntetyczne (zmierzone):**
- Wygenerował je sam wytrenowany Delphi-2M, startując od urodzenia. README autorów: dane i model z nich „for coding testing purposes only and we absolutely do not recommend using this model for any type of research".
- `val.bin`: 7144 „pacjentów", w `train.bin` 7143, średnio 25,4 zdarzenia na osobę (maks. 69). Wiek 0–80 lat (0–29 219 dni).
- Format wiersza: `(id_pacjenta, wiek_w_dniach, token_pliku)`. **Token modelu = token_pliku + 1**: 0 to padding, 1 to „No event", a przesunięcie dokłada `get_batch`.
- Słownik (indeks = wiersz `labels.csv`): 0 Padding, 1 No event, 2 Female, 3 Male, 4–12 styl życia (BMI / Smoking / Alcohol × low / mid / high), 13–1268 choroby ICD-10, 1269 Death. 1255 kodów 3-znakowych, wyłącznie rozdziały **A–Q** (brak R, S–T, V–Z). Kod `O01` występuje dwa razy: token 936 i token 1268 z etykietą „O01 Hydatidiform mole38", czyli błąd w pliku autorów.
- 5,1% zdarzeń przypada przed 18. r.ż. Najczęstsze: J45 astma (261), J30 (197), B01 ospa (145), B05 odra (110), L30, J03, G43, B26 świnka. W UK Biobank to choroby z dzieciństwa podane przez dorosłych z wywiadu, a dla sali pediatrów dobry haczyk.

**Model i matematyka (z `model.py` i notebooków autorów):**
- `Delphi(DelphiConfig(...))`, config demo: `n_layer=12, n_head=12, n_embd=120, block_size=96, vocab_size=1270, bias=False, t_min=0.1, mask_ties=True, ignore_tokens=[0,2,…,12]`. Daje **2 243 400 parametrów** (konstruktor drukuje „number of parameters: 2.24M").
- `forward(idx, age)` zwraca `(logity (B,T,1270), loss, attention (L,B,H,T,T))`. Wiek podajemy w **dniach**, jako float.
- logit `l_k` = log tempa zdarzenia k **na dzień**. P(następne = k) = softmax(l). Ryzyko roczne: `1 − exp(−exp(l_k)·365,25)` (`evaluate_delphi.ipynb`). Oczekiwany czas do następnego zdarzenia to `1/Σexp(l)`.
- `Delphi.generate(idx, age, max_new_tokens, max_age, no_repeat=True, termination_tokens=[1269])` losuje konkurujące wykładnicze: `t_k = −exp(−l_k)·log U`, `argmin`. Tokeny z `ignore_tokens` i choroby już obecne (oprócz „No event") są maskowane. Używa `torch.isin`, którego **nie ma na MPS w torch 2.3.0** (`NotImplementedError: aten::isin.Tensor_Tensor_out`), więc wnioskowanie robimy na CPU.
- Warunkowanie „pacjent ma dziś X lat": autorzy dopisują token 1 („No event") w wieku cięcia (`sampling_trajectories.ipynb`). W treningu `get_batch` wstawia „No event" średnio co 5 lat (`no_event_token_rate=5`).

**Środowisko i czasy (M1 Pro 10 rdzeni, 32 GB, macOS 15.6.1, uv 0.9.7):**
- `uv sync` z Python 3.11.10, torch 2.3.0, numpy 1.26.4, pandas 2.3.3 (bez górnej granicy uv wybiera pandas **3.0.6**, dlatego przypinamy `<3`), matplotlib 3.11.2, ipywidgets 8.1.9, nbconvert 7.17.2, pytest 9.1.1. `torch.backends.mps.is_available() == True`.
- `train.py` importuje tylko numpy i torch. `torchvision`, `shap`, `umap-learn`, `statsmodels` i `seaborn` z `requirements.txt` autorów są potrzebne wyłącznie ich notebookom analitycznym, więc ich nie instalujemy.
- **Trening demo (config autorów, 5000 kroków, batch 128):**
  - MPS: **zmierzone 48,6 min** (`time`: real 2917 s), ale w tym czasie na CPU szły równolegle inne obliczenia. Bez obciążenia krok trwa 335–433 ms, z obciążeniem mediana 530 ms; do tego 20 ewaluacji po ~14 s. Czysty przebieg szacujemy na ~40 min, w planie przyjmujemy **40–50 min**;
  - CPU: ~1,1–1,5 s/krok, czyli ok. 1,5–2 h, ok. 3× wolniej niż MPS;
  - README autorów: „around 10 minutes on a single GPU"; pełny Delphi-2M na UKB na MPS to ~10 h.
  - Strata walidacyjna (trening + czas): 3414 po 100 krokach, 72,4 po 200, 13,35 po 250, 12,22 po 1250, **najniższa 12,20 w kroku 2000**. Potem rośnie do 13,02 w kroku 5000, choć treningowa spada do 10,90: to **przeuczenie** na 7 tys. pacjentów. `train.py` zapisuje tylko najlepszy checkpoint, więc dostajemy model z kroku 2000. Na sali to klamra z demo GRU („gdy krzywa walidacyjna rośnie, model zapamiętuje"), a `wykresy.krzywa_uczenia` zaznacza najlepszy krok.
  - Checkpoint `ckpt.pt` waży 27,4 MB z optymalizatorem; po odchudzeniu do samych wag ~9,5 MB.
- **Wnioskowanie (CPU, wytrenowany model):**
  - ranking następnych zdarzeń: 0,005–0,016 s;
  - jedno życie token po tokenie: 0,08–0,23 s;
  - krzywe Monte Carlo: N=100 → 5,0 s, N=200 → 6,3–6,5 s, N=500 → 25 s.
  - Na MPS ranking trwa ~2,1 s (narzut), a `generate` się wywraca (patrz wyżej).
- **Kontrola poprawności Monte Carlo:** 150 losowych pacjentów syntetycznych uciętych w 60. r.ż., po 40 losowań każdy. Model daje średnio 3,6% zgonów w wieku 60–70. Empirycznie w tych samych danych: 1,3% dla tych 150 osób i 2,6% dla całego `val.bin`. Ten sam rząd wielkości, więc potok (wejście + `generate`) jest spójny z danymi.
- **Krzywe dla przykładu „K, 60 l., E11 50, I10 55" (N=1000, 10 lat):** zawał 2,5% vs 1,4% bez cukrzycy, niewydolność serca 2,7% vs 1,0%, przewlekła choroba nerek 4,1% vs 2,6%, zgon 0,5% vs 0%. Kierunek się zgadza, ale poziomy są nierealistycznie niskie. Osoba z dwiema diagnozami wygląda w danych na „zdrowszą niż przeciętna" (artefakt danych, o którym mówi slajd 17). Notebook mówi to wprost.
- Model po 200 krokach produkuje bzdury (w rankingu wady wrodzone i choroby noworodków u 60-latki). Po treningu w rankingu dla „K, 60 l., E11 50, I10 55" są choroby typowe dla wieku: E78 zaburzenia lipidowe (p = 0,046; ryzyko roczne 1,8%), M19, H26 zaćma, K44, K57, E14, K21, E03, M17, I20 dławica. Kod jest na licencji MIT, ale go nie kopiujemy: klonujemy do delphi/zewnetrzne/ (poza gitem),
```python
razem z danymi syntetycznymi autorów. Notebook tylko CZYTA te pliki, nie dotyka sieci.
"""
from __future__ import annotations

import functools
import importlib.util
import subprocess
from pathlib import Path

KATALOG_DELPHI = Path(__file__).resolve().parents[2]
KATALOG_ZEWN = KATALOG_DELPHI / "zewnetrzne"
KATALOG_PAMIECI = KATALOG_DELPHI / "pamiec"
REPO_URL = "https://github.com/gerstung-lab/Delphi"
COMMIT = "fb72166be6b29d8db819227a59487e51c1df1454"   # main z 2026-08-07 („Update README.md")

KOMUNIKAT_BRAK_KODU = (
    "Brak kodu Delphi w delphi/zewnetrzne/Delphi. Uruchom najpierw (z internetem): "
    "cd delphi && uv run python scripts/przygotuj_demo.py"
)


def katalog_kodu() -> Path:
    return KATALOG_ZEWN / "Delphi"


def sklonuj() -> Path:
    """Klonuje repo autorów (jeśli go nie ma) i ustawia przypięty commit. Wymaga internetu."""
    cel = katalog_kodu()
    if not (cel / ".git").exists():
        cel.parent.mkdir(parents=True, exist_ok=True)
        subprocess.run(["git", "clone", "-q", REPO_URL, str(cel)], check=True)
    subprocess.run(["git", "-C", str(cel), "checkout", "-q", COMMIT], check=True)
    return cel


def sprawdz_kod() -> Path:
    """Ścieżka do kodu autorów; czytelny błąd, gdy przygotowanie nie było uruchomione."""
    cel = katalog_kodu()
    if not (cel / "model.py").exists():
        raise FileNotFoundError(KOMUNIKAT_BRAK_KODU)
    return cel


@functools.lru_cache(maxsize=1)
def modul_modelu():
    """Moduł model.py autorów (klasy Delphi i DelphiConfig), wczytany bez zmiany sys.path."""
    sciezka = sprawdz_kod() / "model.py"
    spec = importlib.util.spec_from_file_location("delphi_autorzy_model", sciezka)
    modul = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(modul)
    return modul


def katalog_danych() -> Path:
    """Dane syntetyczne autorów: train.bin, val.bin, labels.csv."""
    return sprawdz_kod() / "data" / "ukb_simulated_data"


def sciezka_etykiet() -> Path:
    return katalog_danych() / "labels.csv"


def sciezka_rozdzialow() -> Path:
    """Tabela autorów: token → rozdział ICD-10 i kolor (do wykresów)."""
    return sprawdz_kod() / "delphi_labels_chapters_colours_icd.csv"
```

```python
class Slownik:
    etykiety: list[str]               # indeks = token modelu
    kod_do_tokenu: dict[str, int]     # "E11" → 215; tokeny specjalne pod nazwą autorów („Smoking_high")
    rozdzial: list[str]               # skrócona nazwa rozdziału ICD-10 (z tabeli autorów)
    kolor: list[str]                  # kolor rozdziału (#rrggbb)

    def kod(self, token: int) -> str:
        m = re.match(r"^([A-Z]\d{2})\b", self.etykiety[token])
        return m.group(1) if m else self.etykiety[token]

    def nazwa(self, token: int) -> str:
        kod = self.kod(token)
        if kod in NAZWY_PL:
            return NAZWY_PL[kod]
        opis = self.etykiety[token][len(kod):].strip().strip("()")
        return f"{opis} (ang.)"

    def opisz(self, df: pd.DataFrame) -> pd.DataFrame:
        """Dokleja kolumny „kod" i „nazwa" na początku tabeli z kolumną „token"."""
        wynik = df.copy()
        wynik.insert(0, "nazwa", [self.nazwa(int(t)) for t in df["token"]])
        wynik.insert(0, "kod", [self.kod(int(t)) for t in df["token"]])
        return wynik


def wczytaj_slownik(sciezka_etykiet: Path | None = None,
                    sciezka_rozdzialow: Path | None = None) -> Slownik:
    etykiety = pd.read_csv(sciezka_etykiet or zasoby.sciezka_etykiet(),
                           header=None, sep="\t")[0].astype(str).tolist()
    kod_do_tokenu: dict[str, int] = {}
    for token, etykieta in enumerate(etykiety):
        m = re.match(r"^([A-Z]\d{2})\b", etykieta)
        klucz = m.group(1) if m else etykieta
        kod_do_tokenu.setdefault(klucz, token)          # „O01" występuje 2×: zostaje pierwszy (936)
    roz = pd.read_csv(sciezka_rozdzialow or zasoby.sciezka_rozdzialow())
    return Slownik(etykiety, kod_do_tokenu,
                   roz["ICD-10 Chapter (short)"].astype(str).tolist(), roz["color"].astype(str).tolist())


def parsuj_historie(tekst: str, slownik: Slownik) -> list[Zdarzenie]:
    """„E11 50, I10 w wieku 55,5" → [Zdarzenie(215, 50.0), Zdarzenie(499, 55.5)], posortowane wg wieku.

    Powtórzony kod: zostaje najwcześniejszy wpis (Delphi liczy pierwsze wystąpienie choroby).
    """
    if not tekst.strip():
        return []
    reszta = _SLOWA_DOZWOLONE.sub(" ", _WPIS.sub(" ", tekst))
    if re.search(r"\w", reszta):
        raise BladHistorii(f"Nie rozumiem fragmentu: „{' '.join(reszta.split())}”. "
                           "Wpisz np.: „E11 50, I10 55” (kod ICD-10 i wiek w latach).")
    zdarzenia: dict[int, Zdarzenie] = {}
    nieznane = []
    for m in _WPIS.finditer(tekst):
        kod = m.group("kod")
        kod = kod.upper() if re.fullmatch(r"[A-Za-z]\d{2}", kod) else kod
        wiek = float(m.group("wiek").replace(",", "."))
        if not 0 <= wiek <= 110:
            raise BladHistorii(f"Wiek {wiek:g} przy {kod} jest poza zakresem 0–110 lat.")
        token = slownik.kod_do_tokenu.get(kod)
        if token is None or token in (tokeny.PADDING, tokeny.BRAK_ZDARZENIA, tokeny.SMIERC):
            nieznane.append(kod)
            continue
        if token not in zdarzenia or wiek < zdarzenia[token].wiek_lat:
            zdarzenia[token] = Zdarzenie(token, wiek)
    if nieznane:
        raise BladHistorii(
            f"Model nie zna kodów: {', '.join(nieznane)}. Delphi-2M ma tylko 3-znakowe kody ICD-10 "
            "z rozdziałów A–Q (bez objawów R, urazów S–T i czynników Z).")
    return sorted(zdarzenia.values(), key=lambda z: z.wiek_lat)
```

```python
"""Dane syntetyczne autorów (train.bin / val.bin): pacjenci „wymyśleni" przez wytrenowany Delphi-2M."""
from __future__ import annotations

from pathlib import Path

import numpy as np

from delphi_demo import tokeny
from delphi_demo.tokeny import Zdarzenie


def wczytaj_bin(sciezka: Path) -> np.ndarray:
    """Plik .bin autorów → tablica (n, 3) uint32: id pacjenta, wiek w dniach, token (przesunięty o −1)."""
    return np.fromfile(sciezka, dtype=np.uint32).reshape(-1, 3)


def pacjent(dane: np.ndarray, pid: int) -> list[Zdarzenie]:
    """Historia jednego pacjenta jako tokeny MODELU (w pliku są o 1 mniejsze)."""
    wiersze = dane[dane[:, 0] == pid]
    wiersze = wiersze[np.argsort(wiersze[:, 1], kind="stable")]
    return [Zdarzenie(int(t) + 1, float(d) / tokeny.DNI_W_ROKU) for _, d, t in wiersze]


def statystyki(dane: np.ndarray) -> dict:
    pid = dane[:, 0]
    n_pac = len(np.unique(pid))
    return {
        "pacjentow": n_pac,
        "zdarzen": len(dane),
        "zdarzen_na_pacjenta": len(dane) / n_pac,
        "odsetek_zdarzen_przed_18": float((dane[:, 1] < 18 * tokeny.DNI_W_ROKU).mean()),
    }


def pacjenci_z(dane: np.ndarray, token: int, przed_wiekiem: float | None = None,
               min_zdarzen: int = 1) -> list[int]:
    """Id pacjentów, którzy mają dany token (modelu), opcjonalnie przed danym wiekiem."""
    maska = dane[:, 2] == token - 1
    if przed_wiekiem is not None:
        maska &= dane[:, 1] < przed_wiekiem * tokeny.DNI_W_ROKU
    kandydaci = np.unique(dane[maska, 0])
    pid, liczby = np.unique(dane[:, 0], return_counts=True)
    duze = set(pid[liczby >= min_zdarzen].tolist())
    return [int(p) for p in kandydaci if int(p) in duze]
```

```python
"""Trening Delphi skryptem autorów (train.py) na ich danych syntetycznych + wczytywanie modelu.

Autorzy nie publikują wag Delphi-2M (UK Biobank, dostęp kontrolowany, upload ID 7318).
Dlatego przed prelekcją trenujemy ten sam model (2,24 mln parametrów) na danych syntetycznych z repo.
"""
from __future__ import annotations

import json
import re
import subprocess
import sys
import time
from pathlib import Path

import pandas as pd
import torch

from delphi_demo import zasoby

CONFIG_DEMO = "config/train_delphi_demo.py"
SCIEZKA_MODELU = zasoby.KATALOG_PAMIECI / "delphi_syntetyczny.pt"
KATALOG_TRENINGU = zasoby.KATALOG_PAMIECI / "trening"
KOMUNIKAT_BRAK_MODELU = (
    "Brak wytrenowanego modelu {sciezka}. Przed prelekcją uruchom (ok. 45 min na M1 Pro): "
    "cd delphi && uv run python scripts/przygotuj_demo.py"
)

_ITER = re.compile(r"^iter (\d+): loss ([\d.]+), time ([\d.]+)ms", re.MULTILINE)
_STEP = re.compile(r"^step (\d+): train loss ([\d.]+), val loss ([\d.]+)", re.MULTILINE)


def polecenie_treningu(katalog_wyj: Path, kroki: int = 5000, urzadzenie: str = "mps",
                       co_ile_ewaluacja: int = 250, partie_ewaluacji: int = 25,
                       co_ile_log: int = 25) -> list[str]:
    """Polecenie dla train.py autorów; uruchamiać z cwd = katalog kodu autorów."""
    rozgrzewka = min(500, max(1, kroki // 10))         # config: warmup_iters = 500 przy 5000 krokach
    return [sys.executable, "-u", "train.py", CONFIG_DEMO,
            f"--device={urzadzenie}", f"--out_dir={Path(katalog_wyj).resolve()}",
            f"--max_iters={kroki}", f"--lr_decay_iters={kroki}", f"--warmup_iters={rozgrzewka}",
            f"--eval_interval={co_ile_ewaluacja}", f"--eval_iters={partie_ewaluacji}",
            f"--log_interval={co_ile_log}"]


def trenuj(katalog_wyj: Path = KATALOG_TRENINGU, **kwargs) -> Path:
    """Uruchamia trening, zapisuje trening.log i czas.json w katalog_wyj. Zwraca ścieżkę ckpt.pt."""
    katalog_wyj = Path(katalog_wyj)
    katalog_wyj.mkdir(parents=True, exist_ok=True)
    polecenie = polecenie_treningu(katalog_wyj, **kwargs)
    start = time.time()
    with open(katalog_wyj / "trening.log", "w") as log:
        subprocess.run(polecenie, cwd=zasoby.sprawdz_kod(), stdout=log, stderr=subprocess.STDOUT,
                       check=True)
    czas = time.time() - start
    (katalog_wyj / "czas.json").write_text(json.dumps({"czas_s": round(czas, 1), "polecenie": polecenie[2:]}))
    return katalog_wyj / "ckpt.pt"


def parsuj_log(tekst: str) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Log train.py → (kroki: iter, loss, ms) oraz (ewaluacje: krok, trening, walidacja)."""
    kroki = pd.DataFrame([(int(a), float(b), float(c)) for a, b, c in _ITER.findall(tekst)],
                         columns=["iter", "loss", "ms"])
    ewal = pd.DataFrame([(int(a), float(b), float(c)) for a, b, c in _STEP.findall(tekst)],
                        columns=["krok", "trening", "walidacja"])
    return kroki, ewal


def odchudz_checkpoint(ckpt: Path, cel: Path = SCIEZKA_MODELU) -> Path:
    """Zostawia tylko wagi i konfigurację (bez stanu optymalizatora): ~27 MB → ~9 MB."""
    dane = torch.load(ckpt, map_location="cpu", weights_only=False)
    cel = Path(cel)
    cel.parent.mkdir(parents=True, exist_ok=True)
    torch.save({"model": dane["model"], "model_args": dane["model_args"],
                "iter_num": int(dane["iter_num"]), "best_val_loss": float(dane["best_val_loss"]),
                "zrodlo": "trening na danych syntetycznych gerstung-lab/Delphi (NIE UK Biobank)"}, cel)
    return cel


def zaladuj_model(sciezka: Path = SCIEZKA_MODELU, urzadzenie: str = "cpu"):
    """Wczytuje model Delphi (klasa autorów) w trybie eval."""
    sciezka = Path(sciezka)
    if not sciezka.exists():
        raise FileNotFoundError(KOMUNIKAT_BRAK_MODELU.format(sciezka=sciezka))
    m = zasoby.modul_modelu()
    dane = torch.load(sciezka, map_location=urzadzenie, weights_only=True)
    model = m.Delphi(m.DelphiConfig(**dane["model_args"]))
    model.load_state_dict(dane["model"])
    return model.to(urzadzenie).eval()


def liczba_parametrow(model) -> int:
    return sum(p.numel() for p in model.parameters())
```

```python
"""Prognoza z historii chorób: ranking następnych zdarzeń, krzywe ryzyka, generowanie życia token po tokenie.

Matematyka jak u autorów (sampling_trajectories.ipynb, evaluate_delphi.ipynb):
- logit l_k = log tempa (na dzień) zdarzenia k; P(następne = k) = softmax(l)_k,
- ryzyko k w ciągu t lat przy stałym tempie: 1 − exp(−exp(l_k) · 365,25 · t),
- losowanie: dla każdego k czas T_k ~ Exp(exp(l_k)); wygrywa najkrótszy (konkurujące wykładnicze).
"""
from __future__ import annotations

from dataclasses import dataclass
from typing import Sequence

import numpy as np
import pandas as pd
import torch

from delphi_demo import tokeny
from delphi_demo.tokeny import Zdarzenie

MIN_WIEK_DANYCH = 40.0    # UK Biobank: rekrutacja 40–70 lat (wcześniejsze choroby tylko z wywiadu)
MAKS_WIEK_DANYCH = 80.0   # dane syntetyczne kończą się na 80. roku życia


@dataclass
class Krok:
    """Jeden krok generowania: wylosowany token, wiek i 5 najbardziej prawdopodobnych kandydatów."""
    wiek_lat: float
    token: int
    kandydaci: list[tuple[int, float]]


def ostrzezenia(historia: Sequence[Zdarzenie], wiek_teraz: float) -> list[str]:
    """Uczciwe uwagi o zakresie danych treningowych (do wyświetlenia nad prognozą)."""
    uwagi = []
    if wiek_teraz < MIN_WIEK_DANYCH:
        uwagi.append(f"Wiek {wiek_teraz:g} lat: w UK Biobank nie ma dzieci ani młodych dorosłych "
                     "(rekrutacja 40–70 lat). Prognoza to ekstrapolacja, a choroby z dzieciństwa "
                     "model zna tylko z relacji dorosłych.")
    if wiek_teraz > MAKS_WIEK_DANYCH:
        uwagi.append(f"Wiek {wiek_teraz:g} lat: dane treningowe kończą się na {MAKS_WIEK_DANYCH:g} r.ż.")
    return uwagi


def przygotuj_wejscie(historia: Sequence[Zdarzenie], plec: str, wiek_teraz: float
                      ) -> tuple[torch.Tensor, torch.Tensor]:
    """Sekwencja dla modelu: płeć (wiek 0), „brak zdarzenia" co 5 lat jak w treningu, choroby,
    a na końcu „brak zdarzenia" w wieku_teraz, żeby model wiedział, ile lat ma pacjent dziś."""
    if plec not in ("K", "M"):
        raise ValueError("plec musi być „K” albo „M”")
    for z in historia:
        if z.wiek_lat > wiek_teraz:
            raise ValueError(f"Zdarzenie w wieku {z.wiek_lat:g} jest po wieku „teraz” ({wiek_teraz:g}).")
    co_ile = tokeny.CO_ILE_LAT_BRAK_ZDARZENIA
    kontrolne = [Zdarzenie(tokeny.BRAK_ZDARZENIA, float(w))
                 for w in np.arange(co_ile, wiek_teraz, co_ile)]
    wpisy = sorted([*historia, *kontrolne], key=lambda z: z.wiek_lat)
    wpisy = [Zdarzenie(tokeny.KOBIETA if plec == "K" else tokeny.MEZCZYZNA, 0.0), *wpisy,
             Zdarzenie(tokeny.BRAK_ZDARZENIA, float(wiek_teraz))]
    idx = torch.tensor([[z.token for z in wpisy]], dtype=torch.long)
    wiek = torch.tensor([[z.wiek_lat * tokeny.DNI_W_ROKU for z in wpisy]], dtype=torch.float32)
    return idx, wiek


def _dozwolone_logity(logity: torch.Tensor, idx: torch.Tensor) -> torch.Tensor:
    """Maskuje tokeny techniczne i już obecne choroby (no_repeat jak w Delphi.generate)."""
    l = logity.clone()
    l[..., list(tokeny.IGNOROWANE)] = -torch.inf
    juz = idx.clone()
    juz[juz == tokeny.BRAK_ZDARZENIA] = tokeny.PADDING
    return l.scatter(-1, juz, -torch.inf)


@torch.no_grad()
def ranking(model, historia: Sequence[Zdarzenie], plec: str, wiek_teraz: float,
            top: int = 10) -> pd.DataFrame:
    """Najbardziej prawdopodobne NASTĘPNE zdarzenia (choroby i zgon) dla pacjenta „dziś"."""
    idx, wiek = przygotuj_wejscie(historia, plec, wiek_teraz)
    urz = next(model.parameters()).device
    logity = model(idx.to(urz), wiek.to(urz))[0][0, -1].cpu()
    l = _dozwolone_logity(logity[None], idx)[0]
    l[tokeny.BRAK_ZDARZENIA] = -torch.inf
    p = torch.softmax(l, 0)
    tempo_dzien = torch.exp(l)
    kolejnosc = torch.argsort(l, descending=True)[:top]
    return pd.DataFrame({
        "token": kolejnosc.numpy(),
        "p_nastepna": p[kolejnosc].numpy(),
        "ryzyko_1_rok": (1 - torch.exp(-tempo_dzien[kolejnosc] * tokeny.DNI_W_ROKU)).numpy(),
        "ryzyko_5_lat": (1 - torch.exp(-tempo_dzien[kolejnosc] * tokeny.DNI_W_ROKU * 5)).numpy(),
    })


@torch.no_grad()
def generuj(model, historia: Sequence[Zdarzenie], plec: str, wiek_teraz: float,
            do_wieku: float = MAKS_WIEK_DANYCH, maks_krokow: int = 80, ziarno: int | None = 0,
            top_kandydatow: int = 5) -> list[Krok]:
    """Losuje dalszy ciąg życia token po tokenie (ta sama reguła co Delphi.generate autorów).

    ziarno=None używa globalnego generatora torch (tak robi Delphi.generate; test zgodności).
    Kroki „brak zdarzenia" też są zwracane (pokazują upływ czasu); do wyświetlania można je pominąć.
    """
    gen = None if ziarno is None else torch.Generator().manual_seed(ziarno)
    idx, wiek = przygotuj_wejscie(historia, plec, wiek_teraz)
    urz = next(model.parameters()).device
    kroki: list[Krok] = []
    for _ in range(maks_krokow):
        logity = model(idx.to(urz), wiek.to(urz))[0][:, -1, :].cpu()
        l = _dozwolone_logity(logity, idx)
        u = torch.rand(l.shape, generator=gen)
        czasy = torch.clamp(-torch.exp(-l) * u.log(), min=0, max=365 * 80)
        dt, nastepny = czasy.min(1)
        nowy_wiek = wiek[0, -1] + dt[0]
        if nowy_wiek > do_wieku * tokeny.DNI_W_ROKU:
            break
        p = torch.softmax(l[0], 0)
        top = torch.topk(p, top_kandydatow)
        kroki.append(Krok(float(nowy_wiek) / tokeny.DNI_W_ROKU, int(nastepny[0]),
                          [(int(t), float(v)) for v, t in zip(top.values, top.indices)]))
        idx = torch.cat([idx, nastepny[:, None]], 1)
        wiek = torch.cat([wiek, nowy_wiek.reshape(1, 1)], 1)
        if int(nastepny[0]) == tokeny.SMIERC:
            break
    return kroki


@torch.no_grad()
def krzywe_ryzyka(model, historia: Sequence[Zdarzenie], plec: str, wiek_teraz: float,
                  cele: Sequence[int], horyzont_lat: int = 10, n_probek: int = 200,
                  ziarno: int = 0, maks_krokow: int = 64) -> pd.DataFrame:
    """Monte Carlo: losujemy n_probek dalszych żyć (Delphi.generate autorów) i liczymy,
    jaki odsetek z nich ma daną chorobę do końca każdego roku. Zgon konkuruje z chorobami.

    Wiersz = lata od „dziś" (0..horyzont), kolumna = token celu. Cel już obecny w historii → NaN
    (model nigdy nie losuje drugi raz tej samej choroby, więc 0 byłoby mylące).
    """
    torch.manual_seed(ziarno)
    idx, wiek = przygotuj_wejscie(historia, plec, wiek_teraz)
    urz = next(model.parameters()).device
    koniec = (wiek_teraz + horyzont_lat) * tokeny.DNI_W_ROKU
    gi, ga, _ = model.generate(idx.repeat(n_probek, 1).to(urz), wiek.repeat(n_probek, 1).to(urz),
                               max_new_tokens=maks_krokow, max_age=koniec,
                               termination_tokens=[tokeny.SMIERC])
    gi, ga = gi[:, idx.shape[1]:].cpu(), ga[:, idx.shape[1]:].cpu()
    lata = np.arange(horyzont_lat + 1)
    obecne = {z.token for z in historia}
    wynik = {"lata": lata}
    for cel in cele:
        if cel in obecne:
            wynik[cel] = np.full(len(lata), np.nan)
            continue
        trafienia = gi == cel
        wiek_zd = torch.where(trafienia, ga, torch.full_like(ga, torch.inf)).min(1).values
        lata_do = ((wiek_zd / tokeny.DNI_W_ROKU) - wiek_teraz).numpy()
        wynik[cel] = np.array([(lata_do <= t).mean() for t in lata])
    return pd.DataFrame(wynik)


def ryzyko_stale_tempo(model, historia: Sequence[Zdarzenie], plec: str, wiek_teraz: float,
                       cele: Sequence[int], horyzont_lat: int = 10) -> pd.DataFrame:
    """Szybkie przybliżenie bez losowania: 1 − exp(−tempo · t), tempo zamrożone na „dziś"."""
    idx, wiek = przygotuj_wejscie(historia, plec, wiek_teraz)
    urz = next(model.parameters()).device
    with torch.no_grad():
        l = _dozwolone_logity(model(idx.to(urz), wiek.to(urz))[0][:, -1, :].cpu(), idx)[0]
    lata = np.arange(horyzont_lat + 1)
    obecne = {z.token for z in historia}
    wynik = {"lata": lata}
    for cel in cele:
        tempo = float(torch.exp(l[cel])) * tokeny.DNI_W_ROKU
        wynik[cel] = np.full(len(lata), np.nan) if cel in obecne else 1 - np.exp(-tempo * lata)
    return pd.DataFrame(wynik)
```

```python
def os_zycia(historia: Sequence[Zdarzenie], nazwa: Nazwa, kolor: Callable[[int], str] | None = None,
             wygenerowane: Sequence[Zdarzenie] = (), tytul: str = "Historia pacjenta"):
    """Każde zdarzenie w osobnym wierszu (czytelne także przy 30 zdarzeniach): x = wiek, podpis obok.

def krzywe(df: pd.DataFrame, nazwa: Nazwa, df_porownanie: pd.DataFrame | None = None,
           etykiety: tuple[str, str] = ("pacjent", "porównanie"), tytul: str = "Ryzyko w kolejnych latach"):

            ax.plot(df_porownanie["lata"], 100 * df_porownanie[kol], color=f"C{i}", lw=2, ls="--",
                    label=f"{nazwa(int(kol))} ({etykiety[1]})")
    ax.set_xlabel("lata od dziś"); ax.set_ylabel("skumulowane ryzyko [%]"); ax.set_title(tytul)
    ax.legend(fontsize=8, loc="upper left"); ax.grid(alpha=0.3)

def krzywa_uczenia(ewal: pd.DataFrame, czas_min: float | None = None):
    """Wynik parsuj_log(): kolumny krok, trening, walidacja."""
    fig, ax = plt.subplots(figsize=(7, 4))
    ax.plot(ewal["krok"], ewal["trening"], label="trening")
    ax.plot(ewal["krok"], ewal["walidacja"], label="walidacja (pacjenci odłożeni na bok)")
    najlepszy = int(ewal.loc[ewal["walidacja"].idxmin(), "krok"])

    ax.legend(); ax.grid(alpha=0.3)
    fig.tight_layout()
    return fig


def slad_generowania(kroki, nazwa: Nazwa, ile: int = 8) -> str:
    """Tekstowy ślad jak w demo z nazwami chorób: krok, wiek, wybrany token, kandydaci z p."""
    def krotko(t: int) -> str:
        n = nazwa(t)
        return n if len(n) <= 38 else n[:37] + "…"

    linie = []
    widoczne = [k for k in kroki if k.token != tokeny.BRAK_ZDARZENIA][:ile]
    for n, k in enumerate(widoczne, 1):
        kandydaci = ", ".join([f"{krotko(t)} {100 * p:.0f}%" for t, p in k.kandydaci
                               if t != tokeny.BRAK_ZDARZENIA][:3])
        linie.append(f"{n:>2}. wiek {k.wiek_lat:5.1f} → {krotko(k.token):<38} (kandydaci: {kandydaci})")
    return "\n".join(linie)
```

```python
"""Wyniki policzone przed prelekcją (tryb „z_pamieci": notebook nie liczy Monte Carlo na sali)."""
from __future__ import annotations

import json
from dataclasses import asdict
from io import StringIO
from pathlib import Path

import pandas as pd

from delphi_demo import zasoby
from delphi_demo.prognoza import Krok

KATALOG_WYNIKOW = zasoby.KATALOG_PAMIECI / "wyniki"


def _plik(nazwa: str, katalog: Path | None) -> Path:
    return Path(katalog or KATALOG_WYNIKOW) / f"{nazwa}.json"


def zapisz_tabele(nazwa: str, df: pd.DataFrame, katalog: Path | None = None) -> Path:
    plik = _plik(nazwa, katalog)
    plik.parent.mkdir(parents=True, exist_ok=True)
    df = df.rename(columns=str)                      # tokeny jako nazwy kolumn → tekst w JSON
    plik.write_text(df.to_json(orient="split"))
    return plik


def wczytaj_tabele(nazwa: str, katalog: Path | None = None) -> pd.DataFrame:
    df = pd.read_json(StringIO(_plik(nazwa, katalog).read_text()), orient="split")
    return df.rename(columns=lambda c: int(c) if str(c).isdigit() else c)


def zapisz_kroki(nazwa: str, kroki: list[Krok], katalog: Path | None = None) -> Path:
    plik = _plik(nazwa, katalog)
    plik.parent.mkdir(parents=True, exist_ok=True)
    plik.write_text(json.dumps([asdict(k) for k in kroki]))
    return plik


def wczytaj_kroki(nazwa: str, katalog: Path | None = None) -> list[Krok]:
    surowe = json.loads(_plik(nazwa, katalog).read_text())
    return [Krok(k["wiek_lat"], k["token"], [tuple(x) for x in k["kandydaci"]]) for k in surowe]


def jest(nazwa: str, katalog: Path | None = None) -> bool:
    return _plik(nazwa, katalog).exists()
```
